# M5BO-TowerDefense

## CURRENT FEATURES:
### Towers are placeable (one is a placeholder).
### There are now waves and enemies that can spawn (v0.0.1)
### Enemies can take damage from towers (honing system), and currency is displayed and counted up. 
### The Home Base can now take damage, and upon being drained of health, you will lose.
### Towers can be upgraded, and gain a golden tint and a bigger size, as well as being stronger.
### There is now a second Tower; "Spirit", which is a slightly weaker tower that can teleport around to nearby tiles, and if the base is attacked, it will enter a state of enragement and attack harder. 

### Criterion:
# Enemies automatically follow a path to base. (spawn on the right, move to the left.) 
# Towers can be placed in valid places. Rooks choose their own targets and do damage or effect. (Towers can be placed along the path enemies take, and use honing to target enemies.)
# Waves become heavier and the player can start a new wave via the UI. (Five waves, with stronger enemies spawning more as the waves progress.)
# Earn and spend money on towers and upgrades. (25 for basic enemies, 50 for hard. Upgrades cost 75 for Vampire Towers and 80 for Spirit Towers.)
# Base loses life points as enemies walk through. (Aka reach the left side, upon which the Spirit will be enraged.)
# Simple UI for money, waves, lives, start and pause. (I also have restart and quit buttons.)
# One clear unique twist or unique feature that noticeably influences the way you play. (The Spirit's fleeing mechanic and enragement.)
# The game is playable without crashes or blocking bugs (at least five waves can be played). Mechanics that are ready work reliably and have been tested. 
# Code builds without errors or missing references and is submitted via GitHub.
